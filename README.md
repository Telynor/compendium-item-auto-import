# Compendium Item Auto Import

Foundry VTT v14 module for importing a full Item or Actor compendium into a world folder.

1. Install from the manifest URL in `module.json` and enable the module in your world.
2. As GM, open **Configure Settings → Module Settings → Compendium Item Auto Import** and click **Choose Compendium and Import**.
3. Select an Item or Actor compendium. Select a matching folder from the world Items or Actors sidebar. Create the folder in that sidebar first if needed.
4. Click **Import**. The module imports all entries and reports how many were added.

Selections are remembered. Repeat imports skip entries previously imported by this module. Imported world documents remain independent of their compendium originals. An imported entry moved to another folder is still recognized as already imported. Delete its world document if you want to import it again.
